# Wedding Invitation

Static wedding invitation project.

## Current stage

Stage 1 — UI/HTML structure.

The page structure includes:
- Opening / cover
- Introduction
- Couple
- Countdown
- Wedding events
- Our story
- Gallery
- Google Maps location
- RSVP
- Footer
- Music control
- Gallery lightbox container

CSS and JavaScript will be implemented in the next stages.
